# MathViz · 让数学看得见

> 用交互式可视化理解数学。—— 一个开源数学可视化知识库。

## 理念

数学不应该是"背公式"的学科。MathViz 的目标是用 3D 和 2D 交互可视化，把抽象概念变成可观察、可操作的空间结构。

- **从图像到直觉** — 每个核心概念都配以可交互的视觉演示
- **从直觉到严谨** — 可视化 + 代数推导，两个角度互相印证
- **从知识到体系** — 线代、高数、概率不再是孤立的科目
